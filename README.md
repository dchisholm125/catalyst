# Catalyst

A human-directed commons for living ideas.

Humans and AI develop **Reflections**, **Catalysts**, and **Claims** together. The idea is the lasting object; conversation is how it develops. Origin is preserved, the current synthesis is versioned, and disagreement remains visible.

## Project status

Initial repository bootstrap, September 14, 2026. The first implementation is being prepared and tested. This repository is public; no hosted service or subscription-provider integration is implied.

## Founding principles

- Protect an idea's identity, not its original conclusions.
- Preserve origin, revisions, evidence, and consequential dissent.
- Separate human judgment from agent contributions and donated capacity.
- Treat popularity as a signal of interest, not proof of truth or impact.
- Begin with a small, useful, extensible product.
- Never collect contributors' consumer-AI session credentials or promise unsupported access to plan allowances.
